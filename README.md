# 💰 多平台比价本

一个**打开就能用、数据只存在自己手机里**的比价小工具。把同一件商品在淘宝、京东、拼多多的价格各记一次，工具自动帮你算出**哪个平台最便宜、能省多少**，并在降到你设定的目标价时提醒你。

## ✨ 功能

- 🔍 **自动归类同款**：商品名相同即归为一组，自动排序并标出「最低价」
- 💵 **算出差价**：一眼看到最低价比最高价省多少，首页汇总「最多可省」
- 📈 **价格涨跌**：同一平台更新价格时，自动记录历史并显示涨跌箭头
- 🎯 **目标价提醒**：设置「降到多少提醒我」，达到时弹窗提醒（带振动）
- 💾 **本地存储**：所有数据只保存在您的设备浏览器里，不上传任何服务器
- 📤 **导出/导入备份**：换手机时一键迁移数据
- 👴 **长辈友好**：大字体、大按钮、全中文

## 🚀 使用方法

**在线使用（推荐）**：https://tuyidian.github.io/price-compare/

> 手机浏览器打开后可「添加到主屏幕」，像 App 一样使用。

**本地使用**：下载 `index.html`，用任意浏览器打开。

## 📖 使用步骤

1. 点底部 **「＋ 添加比价」**
2. 填商品名称（同一商品在不同平台要填**完全相同**的名字，例如都填「小米移动电源3 10000mAh」）
3. 选平台、填当前价格，可选填目标价
4. 重复添加其他平台的价格
5. 首页会自动把同款商品归组，标出**最低价**和**可省金额**
6. 价格变化时，点 ✏️ 更新价格，会记录历史涨跌

## ⚠️ 关于「全自动抓价」的说明

淘宝、京东、拼多多等平台有严格的反爬机制，且抓取价格通常违反其用户协议；个人要获取实时价格需通过官方开放平台（如京东联盟、淘宝客）申请资质与 API 权限。因此本工具采用**半自动**方式：您浏览商品时记下价格，工具负责归类、比价、记历史和提醒。这样合规、稳定、无需任何账号授权。
